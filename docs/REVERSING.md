# Reverse-engineering reference

Build 19145763. Function ids (`f@N`) are **hlboot.dat only**; `hlbootdx.dat` numbers differ, so resolve by name (`mod find`).

## Engine

- Shiro Games engine: Haxe → **HashLink bytecode** (`hlboot.dat`; `hlbootdx.dat` = DirectX build). `D4X.exe` is only a launcher. Names and source file/line survive; `.hx` sources are not shipped.
- `crashlink` (pip, in `.venv`) parses/serializes both boot files byte-identically and decompiles to pseudo-Haxe. The decompiler is imperfect (duplicated branches, `var17[1]` for `[i]`); confirm with `--asm`. `$AIMilitary.getSiegeableVillages` hangs the decompiler: use `--asm`.
- Resources: `res.compressed.pak` (Heaps PAK, `tools/pak.py`), then `res.compressed1.pak`, `2`, … up to the first missing number; later files replace same-path files, so two mods replacing `data.cdb` conflict.
- `data.cdb` = CastleDB JSON (~90 sheets). Code reaches rows by id and by index: never reorder or delete rows. Key sheets: `constant` (1309 rows, 415 `AI_*`, `values[]` = per difficulty Easy/Medium/Hard/Insane, or a [min,max] pair for ranges), `unit`, `ability` (`props.ai`), `structure` (`startUnits`), `faction` (`startResources`), `gameMode`, `parameter` (`constOverrides`), `militaryGauge` (`props.onSuccess/onFailure` blocks), `action`, `need`.
- Constants are read via `Const.valueCache[i]` / `fValuesCache[i]` / `iValuesCache[i]` (row index).

## Military decision flow

- **Gauges:** `AIMilitary.regularUpdate` → gauges ≥ `valueCache[1116]` (100) and not paused → `tryGauge(random valid gauge)` → `tryAnnexation/tryPillage/...` → `tryAction(kind, args)` → `tryArmyAction(k, structure, data)` → `onActionEnd(gaugeKind, EReason, data)`: runs `militaryGauge.props.onSuccess/onFailure` blocks (not for `Skip`), un-pauses the gauge, then `impactNeeds` (Success ×`[1117]`, `NotImplemented`/`Dismiss` no change, `ArmyNotStrongEnough` also requests recruitment, else ×`[1118]`). Only Raze has `onFailure` blocks. `getMilitaryGaugeKindFromSiegeActionKind(k)` maps action → gauge.
- **Orders:** `tryArmyAction` → `HAI.getDefaultUnitActionQueryArgs` → `pickUnits` → `AIOrders.addOrder(type, prio, armies, target, action, siegeAction, mandatoryMissions, optionalMissions, data, onComplete)`. Phases: 0 Paused, 1 Waiting, 2 Preparation (paths, possibly Shuttle steps), 3 Regroup, 4 Engage, 5 Action, 6 Retreat. End: `AIOrder.stop(reason)` → `removeOrder`. `AIOrderType`: Basic, Military, Defense(e), Protect(e), Resupply(f,f), Discovery(e), Patrol(e), Investigate(e), SendAssassin(e). `AIOrderTargetType`: Entity, Unit, Army, Ornithopter, Harvester, Structure, Group. `AIOrder.getTarget()` = the targetType enum parameter. `ActionEndReason`: Success, Fail, Cancel, Override.
- **pickUnits** args: `consideredUnits, enemyStructure, enemyUnits, targetFaction, requiredPowerBalance (1), allIn, ignoreMelee, ignoreOtherFactionArmies, simulatePendingArmies, allyStructure, allowShips/Frigates`. Candidates sorted by distance, added one by one, `HPowerScore.compute` (`balance = my / enemy`), returns once balance ≥ required; can count units in recruitment. `tryArmyAction`: no idle units → simulate all armies → `ArmyNotStrongEnough` / `NoAvailableArmy`.
- **getUnits** (siege idle query): minLife 0.9 (if `hasSafeRegen`), minSupply 0.9, excludes armies in orders with priority ≥ the action's `siegeAction.props.aiPrio` (Annex 3, Pillage 1, Liberate 1, Raze 4). Its busy closure (f40983; dx f40930) reads `(target as Structure).siege.isUnderSiege` for Military orders in phase 5: null for non-structure targets (patched, see `busy-siege`).
- **checkStructures:** own structures only; skips those with an order; `siege.isUnderAttack()` → units within 80 → `pickUnits(allyStructure, enemyUnits, getDefenseRandomPowerBalance, ...)` → `addOrder(Defense(s), prio 10 main base / 5)`.
- **getSiegeableVillages** (f@8416): candidate filters (allowNeutral/allowEnemy/unreconned/sietch/mainBase/orders). Wind filter: `considerWater && compareGoals(water) < 0 && structures > 1` → drop zones with `windForce < valueCache[1185]`. `tryAnnexation` sets `allowEnemy=false` below the required aggressiveness.
- **getEnemyCombatStats(structure, units, ignoreOtherFactionArmies)** (callers `pickUnits`, `getOrderPowerBalance`): `structureCombatStats(target)` + owner main base if within its `attackRange` + **owner's** armies weighted by zone distance (`fValuesCache[1067]`/`[1068]`). No third-party armies, no neighbour villages' turrets. `pickUnits` / `getOrderPowerBalance` add `structureCombatStats(allyStructure)` to our side.
- **Combat stats:** `$HCombatStats.structureCombatStats(s)` = [mainBaseCombatStats if main base, siegeCombatStats (militia), buildingCombatStats(b) for each building with power > 0]. Building / main base stats have health 0 (MissileBattery power 40, AOE; main base power 80, AOE; both range 80 in data). `HPowerScore.singlePowerScore(stat)` = offensivePotential × health (0 for turrets); a report's powerScore = Σ offensivePotential × Σ HP × count^`valueCache[1115]`, so turrets add offense only (a lone turret scores 0). `offensivePotential` = (power − enemy armor × penetration) × attackSpeed × damageModifier × aoeFactor × externalFactor.
- **Order cancels:** `checkOrders` cancels when `getTarget().removed`. `checkOrderTerminations` → closure f40838: Group target removed → `stop(null)`; next path step `Shuttle` and `checkUseAbilityOn("Shuttle")` = Invalid(2)/BlockedBy(8) → Cancel; all units dead → Cancel; Military ArmySiege/ArmyFight on a Structure: peace with owner, `!canBeAttacked` or siege lost → Cancel (no Group case). `addOrder`'s onComplete closure f40799: on Success cancels other phase<5 orders sharing units. `AIOrders.onEvent`: `OnNewTreaty` (Breakable, flag bit 4) cancels orders targeting either party; `OnCompleteSiegeAction` → Success. `checkEngageOrder`'s ArmyFight case calls `entityGroup.getEntities()` unconditionally.
- **AIEntityGroup:** `$AIEntityGroup.create(entities, null)`; `updateEntities` (f@8117, from `regularUpdate`) drops removed/dead members and removes the group only when empty; position = centroid; `entities` is a plain ArrayObj (members may be removed from it).
- **Regroup** (`AIOrders.checkRegroupOrder` f@8196): per army, arrived = path at its last-but-one step (the regroup point); `nextPhase` only when arrived count ≥ `order.units.length`, or when a stalled army (no movement for `valueCache[1084]`) has a path ≤ `[1085]` (else Cancel). `AIOrder.nextPhase` (f@5304) = `phase++` + `changePhase`; skipping Regroup with stragglers is a vanilla state.
- **Live order balance:** `getOrderPowerBalance`'s only caller is `AIOrders.tryUseOrderAbilities` (f@8203): in Action, balance < `fValuesCache[961]` → `useAbilities(1)` (emergency abilities). No cancel.
- **World events** (`AIController.checkWorldEvents` f@8253): events with a Discovery-type action within `getDistanceToPlayerTerritory ≤ 1` (any distance when a no-supply unit exists), not deep desert, `isWorldEventActionValid` → `HScoring.worldEvents` → pickMapBest/pickWeight → nearest idle army (`getUnits` minLife 0.8, prio 0, no heroes / attribute 1377) → single `addOrder(Discovery(s), 0, [army], s, "InvestigateEvent")`, result unused; `lastResolvedWorldEventTime` set after the call.
- **Fight retreat** (`unitMicroManagement`, per tick): after `valueCache[1104]` (5 s) of fight, `r = random in fValuesCache[1097]` (re-rolled each tick); if `HAI.getWarzonePowerBalance(wz, faction, ref)` ≤ r: cancel related orders, `Resupply(1,1)` to the nearest non-fighting healing structure (closures f40976 warzone centroid, f40981 army). `getWarzonePowerBalance` (f@22345) counts units within 80 of `Warzone.get_centroid()`; other callers: `HAI.checkWarzonePowerBalance`, `Spying.tryLaunchOperation`.
- **Resupply** (`checkUnits`): armies from `getUnits(minLife 0, minSupply 0, prio 0)` without a Military or Resupply order, with life < `[1063]` or (hasSupply and) supply < `[1062]` → sort `healingStructures` by closure f40973 key (squared distance) → `Resupply(1,1)` Move to the first, armies grouped per structure.
- **Supply:** `Army.getSupplyChanges(resupplyStructure)`: drain only if `isInHostileZone()` (+ wind, deep desert, fighting factors); gain only with a `resupplyStructure` or attribute 449 out of combat. `isLosingSupply` finds `resupplyStructure` in the army's zone or neighbor zones: `Structure.canSupply(army)` = `isStandardSupplyZoneForFaction` (allied default supply zone, allied sietch, attribute 460) && `isInSupplyRange` (`isNear` the structure or one of its buildings). Neutral villages supply only armies with attribute 459. `updateSupply` (f@7339): `preventLoss` when a structure in the army's zone `canSupply` it; `isInHostileZone` (f@7338) is false while `occupiedStructure.siege.isInOccupationRange(army)`, during a running `InvestigateEvent`, when deployed as harvester, or with attribute 448. `SiegeComponent.occupationActionEffects`: reward effect Resupply (Pillage `rewards.effects` = Pillage|Resupply) adds `valueCache[153]` (0.5) + attributes 979/980 × maxSupply to each occupying army.
- **World/zone access:** `Game.inst.world` → `World.getZoneAt(x, y)` (f@13851); `Zone.owner`, `windForce`, `neighbors`, `armies`, `structures`. `SiegeComponent`: `isUnderSiege`, `besiegers`, `besiegingFaction`, `occupier`, `contested`.
- **Diplomacy/treaties:** `State.areAtWar` (f@13999) = status `War`. `hostileAction.Combat_Allowed` = War; `Combat_Disallowed` = Peace (Truce), TributeLiege/Subject; Team = Alliance. Vanilla daily `desiredStatus` (0 peace / 1 war / 2 total war) from `HScoring.diplomaticTarget`; peace offered at status 0 with chance `valueCache[279]`; accepted unless status 2, by trade value only.
- `EReason` (ability/action results) includes `Dismiss`, `Skip`, `NoAvailableArmy`, `NotEnoughArmies`, `ArmyNotStrongEnough`, `InsufficientSupply`, `NoStructuresWithSufficientWind`; resolve indexes from the enum constructs, never hard-code.

## AI rules (tools/rules/, wired by tools/behave.py; testbed patch `aware-ai`, installed with `ai-log`)

Thresholds and rationale: AI-POLICY §4. All rules run in traps; on error vanilla continues.

- **Shared queries:** `aimod_pw(unit)` = singlePowerScore(unitCombatStats). `aimod_threat(fac, p, r)` = at-war army power within r of p plus moving armies with `(d - r) / speed ≤ 20 s` (`aimod_threat_now`: 3 s horizon). `aimod_own(fac, p, r, exclude)`. `aimod_terrain(fac, zone)` = 1.3 own zone, 0.8 zone owned by an at-war faction, else 1. `aimod_land(fac, e)` = distance to fac's nearest structure standing on a zone fac owns (skips UWHeadquarters in enemy villages). `aimod_supok(a, d, k)` = supply ≥ k × (0.35 × d + 0.1 × maxSupply) (true without supply). `aimod_short(fac, a)` = `isLosingSupply` and not `supok(a, land(a), 1)`. `aimod_sieged(fac, s)` = `s.siege.besiegingFaction` (else `getOccupierFaction()`) is at war with fac, and s is neutral, ours or of a faction not at war with us. `aimod_cover(fac, e, exclude, own, res)` = Σ offensivePotential × 1500 over the health-0 stats of every structure (≠ exclude) within 130 of e, owned by fac (own) or by an at-war faction (`State.factions` → `structures`); skips besieged villages (silent) and inactive main bases (`get_isActiveMainBase`); pushes the stats into res if not null. `aimod_silence(res, s, c)` = remove health-0 stats from res[0..c) unless s is a main base. `aimod_defend(fac)` = first of our villages / main bases with `aimod_sieged`, else null (defensive posture). `aimod_free(army, orders)` = alive, controlled, not militia/transported, life and supply ≥ 0.9, in no order except Patrol (checked against `orders`; null = only `aiOrder`).
- **retreat-terrain:** both `$HAI.getWarzonePowerBalance` calls in `unitMicroManagement` → wrapper returning balance × `aimod_terrain(faction, World.getZoneAt(centroid))` × supply factor (1 − 0.6 × power share of our armies within 80 of the centroid that are `short`). Data sets RetreatRatio to [0.65, 0.65]. Logs `retreat` (raw, tf, sf, adj).
- **safe-heal:** the three healing-structure key closures (f40973, f40976, f40981) → wrappers adding to the squared-distance key. Army at the structure (≤ 120): +2^28 only if `aimod_threat_now(s, 80)` > (own within 80 + army) × 2 × 1.3, else nothing. Otherwise `aimod_unsafe(s, army, sticky)`: level 1 (threat within 300 > own × terrain × (2 if it is the army's current Resupply target)) → +250²; level 2 (threat > (own + army) × terrain × 2) → +2^28. Logs `heal`.
- **hunt** (`aimod_hunt`, per scan): target = `AIEntityGroup` of at-war armies within 250 of the anchor; order `addOrder(Military, 5, freeArmies, group, "ArmyFight")` via the logging wrapper. Hunts = Military + targetType Group (vanilla Group orders are Defense).
  - Start (every 10 s, max one, ≥ 30 s after the faction's previous start). Candidates: chase = prey visible, at war, `land` ≤ 500 (≤ 300 if on its own zone), anchor = prey, weight 1; contest = a `State.villages` entry with `aimod_sieged` and `land` ≤ 500, anchor = village, weight 3. H = max(threat(anchor), threat(prey)) + T (T = enemy `aimod_cover` at the anchor, anchor excluded); M = our cover there + free armies within 450 of the anchor (900 for our own village) with `supok(a, land(anchor), 1.25)`; at least one free army; needs M ≥ 1.5 × H / terrain(anchor zone). Chases while defensive (`aimod_defend` non-null) or with T > 0: only with nearest free army ≤ 150 and M ≥ 3 × H / terrain. Defensive: contests only on our own villages. Pick max weight × H / (nearest free army distance + 100). Group = at-war armies within 250 of the anchor (none → no start). For 30 s after an `objective` abort only contests may start.
  - Abort pass setup: core = the live member with the smallest `aimod_land` (sd); members farther than LOCAL (250) from the core are removed from `g.entities` (split off: the order target follows the prey); threat, cover, terrain and our nearest order army (dn) are measured at the core, not the centroid.
  - Engage (after every abort trigger passed): an order in Regroup (phase 3) whose armies within LOCAL of the core (+ our cover) have ≥ ENTER × H / terrain → `nextPhase` (logging wrapper) → Engage; logs hunt `engage`.
  - Abort (every 3 s, `stop(Cancel)`, first trigger wins; sd = min over live members of `aimod_land`): gone, truce (no member at war), leash (sd > 650), home (all members on their own zone and sd > 400), supply (an order army `short`, in contact too), drift (sd > 575 and none of ours within 150), lost (none visible and none of ours within 250), weak (order power + our cover < 0.7 × (threat(group) + enemy cover) / terrain(member zone)), objective (no sieged village within 250 of the group, and one with `land` ≤ 500 that this hunt's armies pass the contest start test for: free, within 450, supply budget, power ≥ 1.5 × threat / terrain; the start gap is lifted), defend (defensive posture, not a contest, and not (nearest order army ≤ 150 and power ≥ 3 × (threat + cover) / terrain)), turret (not a contest, enemy cover at the group > 0, same contact / 3× exception).
- **turret/third-party-aware sizing:** in `pickUnits` and `getOrderPowerBalance`, the `getEnemyCombatStats` call → wrapper (target not ours: `aimod_silence` its own turrets, `aimod_cover` pushes at-war neighbours' turret stats, then unless `ignoreOtherFactionArmies` is true or `units` is non-empty: `aimod_threat_stats(fac, s, LOCAL, s.owner, res, s.zone)` = the `aimod_threat` armies minus the owner's, each pushed as `unitSimulatedCombatStats(army, zone)` (f@22340, externalFactor untouched)) and the `structureCombatStats(allyStructure)` call → wrapper (our structure: silenced while besieged, our neighbours' turrets pushed). `ignoreOtherFactionArmies` is true only on own-village defense picks.
- **discovery-gate:** the single `addOrder` call in `checkWorldEvents` → wrapper: refuse (return null, log `disc`) when `aimod_threat(fac, event, LOCAL)` > 0 and `pw(army) < ENTER × threat / terrain(event zone)`; else the logging addOrder wrapper.
- **bunker score:** the `tryAction → $HScoring.structures` call → wrapper: positive scores × 1.3 for structures within 130 of one of our structures on our land, or 200 of our main base.
- **siege launch gate** (`annex-spacing` wrapper on the single `tryAction → tryArmyAction(k, s, data)` call; `tryAction` = `getSiegeableVillages` → `HScoring.structures` → `pickMapBest`/`pickWeight` → tryArmyAction): 1. `aimod_defend` non-null → refuse (`space` why defend); 2. k = "Annex" (`String.__compare`) and a village within 200 of our active main base is neutral or at war with us and not targeted by one of our Military orders → s replaced by it (`bunker`; bypasses score and the aggressiveness gate; *unverified*: the occupation cost was checked by tryAction for the original s only); 3. one of our Military orders targets another structure within 100 → refuse (`space` why space). Refuse = `onActionEnd(gauge(k), Dismiss, data)`; `space` logged once per faction per 10 s.
- **busy-siege:** in the getUnits busy closure, `NullCheck s` → `JNull s` to the priority check (same size, located via the (ctx, AIOrder)->Bool closure in `getUnits`).
- **raid** (`rules/raid.py`, per scan after hunt; `behave` builds tick = hunt then raid): candidates = `State.villages` owned by an at-war faction, not a main base, `siege.besiegingFaction` null, "Pillage" in `siege.getAvailableOccupationActions(fac)` (`String.__compare`), not a target of our Military orders. Force = our armies within RAID_R with `aimod_free` variant (life ≥ RAID_LIFE, any supply, Patrol/Resupply orders allowed) and `aimod_raidsup(a, d_to, land(s))` (arrive ≥ 25% max, +50% refill capped at max, ≥ SUP_U × land + 10% max) + our cover; H = `aimod_threat(s, LOCAL)` + enemy cover + `aimod_militia(s)` (Σ singlePowerScore > 0 of `structureCombatStats(s)`); needs M ≥ ENTER × H / terrain; nearest candidate wins; `addOrder(Military, 1, armies, s, "ArmySiege", "Pillage", [], [], null, null)` via the logging wrapper (onComplete is null-checked by addOrder's closure f40799). Not while `aimod_defend`; one per faction per RAID_GAP. Logs `raid`.
- **Added globals:** `rules.common._global_map(name)` appends a `haxe.ds.ObjectMap` global (`code.global_types.append`), created on first use with `haxe.ds.$ObjectMap.__constructor__`. Maps: `raid` (faction → last raid launch), `hunt` (faction → last start time), `hobj` (faction → last `objective` abort), `heal` / `retreat` / `space` (log throttles). Not saved with the game.
- **Vanilla movement stall:** `AIOrders.checkRegroupOrder` (f@8196) cancels an order (`Cancel`, stop src `AIOrders.checkRegroupOrder`) whose armies didn't move for a while and whose remaining path is longer than `valueCache[1085]`; armies held in a fight by micro trip it (Resupply orders cancelled and re-issued while starving).

## Decision logging (tools/inject.py, patch `ai-log`)

- **Technique:** new functions are appended (`FB` builder); existing `Call*` ops get their `fun` swapped to a same-signature wrapper, or an `InstanceClosure` op its function. No op insertion, so no jump fixups. `aimod_log(obj)` writes `AIMOD {…}` to `game.log`; `aimod_ent(x)` = `{k kind, o owner, p placeName, x, y}`.
- **Events:** pick (pickUnits), pw (compute inside pickUnits), order (addOrder ×16), end (removeOrder), phase (changePhase/nextPhase), fightb/fpw (getOrderPowerBalance: live my/enemy power), mark (L key / `info`), snap (daily), fight (initFight), micro (changeArmyMicro), stop (AIOrder.stop, one wrapper per caller → `src`; `<none>` = an unnamed closure), call (generic traces from `testbed/ailog.json`), aw, hunt, heal, retreat, space. Every event has `g` (game seconds) and `t` (app seconds). Field lists: aireport.py docstring.
- `end.n` = order army entries, not deaths; use fpw for losses. The game truncates long arrays without a closing `]`; parsers must tolerate it.
- **Generic tracer:** `testbed/ailog.json` `trace` / `trace_per_caller`. Arguments described by static type. Virtual/closure-only functions are untraceable. Keep per-tick functions out; `mod log` flags traces above 30/game-minute.
- **Safety rules for injected code:** never throw into game code: wrap in `Trap` (`FB.try_`/`end_try`), keep the original call outside the trap, read fields with `$Reflect.field` (a `DynGet` of a missing field throws), `ToDyn` only for primitives (pointers take `Mov`; `ToDyn` on a pointer boxes it). Check `mod log`'s `HEALTH` line after every run.
- **Builder notes:** no float constants (use `Int` + `ToSFloat`, `_ratio`); backward jumps need a `Label` op; labels must be unique per function (`_uid`); `aware.B` wraps typed Call/Field/SafeCast.

## Patching code

1. Read the target with `mod dec <name>`, confirm with `--asm`.
2. In-place edits: a locator in `tools/boot.py` (function by name + exact instruction pattern + original value). Logic: an appended function plus a redirected call site (rules/*.py or inject.py). Register in `patches/bytecode.json`.
3. `boot.apply` re-parses the output and checks the diff size. Test both boot files.
